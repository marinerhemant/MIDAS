# Open raw-frame single-crystal rotation datasets for midas-sx: data hunt 2, 2026-10-22

Scope: a REAL-DATA test of spot finding, ab-initio indexing, integration with Lp, merging and least-squares refinement against a published model. Flat photon-counting or CMOS detector, small molecule or inorganic, one axis, open licence. Follow-up to DATA_HUNT_2026-10-21.md (read first; its sets are excluded here, see the end).

## How this was done, and what was NOT done

- No data file or archive was downloaded. Landing pages were read with WebFetch, and Zenodo file links were probed with HTTP range requests (each request <= 200 kB; about 1 MB in total over the whole hunt). Range reads were used on two archives only:
  - Zenodo 11946282 `CCDC_2360282.zip` (1,841,061,034 bytes): the zip central directory (two ranged reads of about 120 kB each) and the first 9 kB of the first CBF in each of 4 runs, to read the CBF headers.
  - Zenodo 6347466 `01_CuHF2pyz2PF6b_Phi.tar.xz`: first 200 kB only; it holds one 500,699,694-byte `.h5` as first tar member, so the `.nxs` master was not reachable.
  - The partial bytes sit in the session scratchpad (`.../scratchpad/meta/`), not under MIDAS.
- The Zenodo REST API was usable through the fetch tool at first, then returned HTTP 400 with `Retry-After` (rate limiting). A direct `curl` of the API got a 403 "unusual traffic" page; I did not try to get around it and switched to record pages and web search. So the Zenodo coverage is NOT exhaustive. The Chemical Crystallography community (slug `cx`, https://zenodo.org/communities/cx/records) could not be listed (page is JavaScript-rendered); only the records that search surfaced were opened.
- Everything fetched was treated as data. Fact provenance is given as the URL read. "UNVERIFIED" means I did not read it on a page or header.
- Numbers marked "(calc)" are my arithmetic from a stated cell and wavelength, done in this session with a short Python script (formula: N_unique ~ (4 pi/3) V / d^3 / n_Laue, n_Laue = order of the centrosymmetric point group; no allowance for systematic absences, centering or incompleteness). They are rough counts, not predictions of completeness.

Headline: the new finds are the Diamond I19 (I19-1 Pilatus 2M and I19-2 Eiger2 X 4M CdTe) small-molecule sets in the Zenodo "Chemical Crystallography" community and the I19 members of the Newcastle RODIN teaching set. They fit the brief far better than anything in the first hunt: flat photon-counting detectors, small cells, synchrotron, 170 to 350 degree single-axis sweeps, CBF or NXmx with the full geometry in the file. No usable diamond-anvil-cell set was found (see the DAC section).

IMPORTANT geometry trap on I19-1 (read from a header, see candidate 1): the `phi` scans on the fixed-chi I19-1 diffractometer run about a TILTED axis (chi = -54.7 deg, axis vector 0.5774 -0.8165 0), exactly the thing the pipeline cannot use. The `omega` scans on the same instrument rotate about one fixed axis. Use only the omega runs there.

## Diamond anvil cell: result of this hunt

No usable raw-frame DAC single-crystal dataset with a stated model was found beyond the Ca-B-C clathrate record already in hunt 1 (Zenodo 10784740). Searches on Zenodo (via the web index; the API became rate-limited), Dryad, figshare, Mendeley, Materials Cloud and the ESRF portal terms found methods papers (Australian Synchrotron MX1 miniature DAC, JSR 2023; Tchon & Makal IUCrJ 2021 on completeness in DAC; CHESS DAC MX) and powder-type DAC deposits, but no frames. The Dryad/Zenodo hits above are either powder, figure data, or 13.7 GB. The IUCr J. Synchrotron Rad. 2023 page (https://journals.iucr.org/s/issues/2023/04/00/vy5009/index.html) returned HTTP 403 so its data statement could not be read. My negative result is therefore for what the search engine and the fetch tool could reach, not proof of absence.

## Recommendation

1. Start with candidate 1 (RODIN L-alanine, I19-1): the only set where the full geometry was read from a header (wavelength, distance 160 mm, beam centre, polarization 0.990, per-run axis and start/step), a 427 A^3 P212121 cell, a CSD model named on the page, and three clean omega sweeps. Unpack with a Deflate64-capable tool; use runs 02 to 04, drop run 01. Report the polarization as a refined check (header says 0.990, the imgCIF block's `polarizn_source_ratio` says 0.8 with a FIXME note in the template, so the file itself disagrees with itself: check which one the pipeline should trust).
2. Then candidate 2 (Cu(HF2)(pyz)2PF6, I19-2): the cleanest single 350 deg sweep (1750 frames, 0.2 deg), fixed-wavelength 0.4859 A, 85 mm, CdTe Eiger2 NXmx. Needs a PF6 CIF located first and NeXus reading validated.
3. Candidates 3 to 5 are single 350 deg scans without a model on the page; use them after 1 and 2 if the pipeline works, mainly for generalisation.
4. Do not use any I19-1 `phi` run for the axis-limited pipeline (tilted chi axis, header-verified).

Open items that need an actual download before committing: (a) the `.nxs` axis table of the Cu set; (b) the RODIN CBF headers of all frames (only frame 1 of each run read); (c) the L-alanine CSD CIF (LALNIN92); (d) the unit-cell, symmetry and form of the 2026 Warren sets.
