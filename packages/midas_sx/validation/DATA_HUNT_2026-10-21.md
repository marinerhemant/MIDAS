# Open raw-frame single-crystal rotation datasets for midas-sx: data hunt, 2026-10-21

Scope: monochromatic rotation-method frames on a 2-D detector, open licence, DOI host, published model. Only landing pages, file listings and (for Zenodo) the REST API metadata were read. No data file was downloaded and no archive was opened. Everything below that comes from inside an archive (headers, frame counts) is therefore UNVERIFIED unless a page states it. Every URL below was opened during this hunt; the page text is the provenance for each number (Zenodo record pages, Zenodo API listings, SBGrid and proteindiffraction.org dataset pages, one imgCIF file read as text).

Headline finding: open raw frames with complete metadata are common for protein crystals and rare for small molecules. Of the sets found, only the Australian Synchrotron Rochelle-salt set carries a machine-readable full geometry on the record. For diamond anvil cells I found exactly one candidate (Ca-B-C clathrates, Zenodo 10784740), and what is inside it is unknown. No other DAC raw-frame deposit turned up in repeated searches (Zenodo API, Figshare, Dryad, Princeton, Edinburgh, ESRF portal text). The ESRF data portal itself needs JavaScript, was not opened, and its embargo is 3 years, so ESRF DAC frames may exist there but were not checked.

Format and reader summary (readers checked against the fabio docs page and the dxtbx GitHub directory listing; nothing was run):
- SMV/ADSC: fabio (`dtrekimage`/`adscimage` compatibility module) and dxtbx `FormatSMVADSC` (Q4, Q210, Q315, Q270). Listed.
- CBF: fabio `cbfimage`, dxtbx `FormatCBF*`. Listed.
- Bruker SFRM: fabio `bruker100image`, dxtbx `FormatBruker`/`FormatBrukerFixedChi`/`FormatBrukerModern`. Listed.
- HDF5/NeXus (Eiger): h5py, fabio `eigerimage`/`hdf5image`, dxtbx `FormatNexus`, `FormatHDF5EigerNearlyNexus`, `FormatNXmx*`. Listed. Eiger master files need the hdf5 bitshuffle/LZ4 filter plugin (hdf5plugin) to read the data files: not checked.
- Rigaku `.rodhypix` (CrysAlisPro HyPix): NO reader found. fabio and dxtbx listings (both partly truncated) show none. UNVERIFIED that none exists.
- STOE `.xi`: NO reader found. UNVERIFIED.

## Ranked shortlist

### 1. Rochelle salt, Australian Synchrotron MX1 (best first test)
- Title: Australian Synchrotron beamline calibration dataset from Rochelle salt
- URL: https://zenodo.org/records/7265997 ; DOI 10.5281/zenodo.7265997 ; Zenodo ; CC BY 4.0 ; no login
- Authors: J. Hester, A. Edwards (ANSTO). Published 2022-10-31 (data collected Aug 2010).
- Files: `ktart2.tar.bz2` 717.2 MB (ADSC/SMV originals), `ktart2_cbf.tar.bz2` 728.6 MB (same frames as CBF), `ktart2_cbf.imgcif` 62.5 kB (metadata). Total 1.4 GB.
- From the imgCIF text (read via https://zenodo.org/records/7265997/files/ktart2_cbf.imgcif):
  - 360 frames, one scan SCAN01, 1.0 s each, 2048 x 2048 pixels, pixel 102.4 um.
  - Scanned axis: `phi`, vector (1 0 0), start 0.0 deg, step 1.0 deg, range 360 deg. Only phi is scanned; omega, chi, kappa are not defined at all in the file. This is as close to the "single axis, everything else fixed" case as it gets.
  - Wavelength 0.708457 (unit not written; Å by imgCIF convention).
  - Detector translation `trans` = 85.93 (unit not written, presumably mm; this is the distance candidate). `two_theta` axis exists but is not scanned and has no value given (presumably 0).
  - Beam-centre candidate: detector offset (105.0, -104.562) mm = (1025.4, 1021.1) px at 102.4 um/px (my arithmetic). The file does not label it as the beam centre and the sign convention was not checked. UNVERIFIED.
- Instrument: Australian Synchrotron MX1. Detector model not named; 2048 x 2048 at 102.4 um is consistent with an ADSC Q315 binned 3x3, which is a guess. dxtbx has `FormatSMVADSC` for that family.
- Crystal: Rochelle salt, KNaC4H4O6.4H2O. The record gives no cell, space group or model ("no structure solution or refinement performed"). From general knowledge it is orthorhombic P2_12_12 with a published structure in the literature/COD; no CIF is linked from the record. UNVERIFIED, you must fetch a reference CIF yourself.
- Missing: unit cell, space group, model, polarization (MX1 is a bending-magnet line, horizontal polarization expected, not stated), explicit distance/beam-centre labels, detector model, frame count only from imgCIF.
- Unusual: plain 360 degree phi sweep of a small-molecule hydrate, NaK tartrate is a light-atom (K) structure with a modest absorption. Possible radiation-damage drift. Not a DAC.
- Format/reader: SMV (ADSC) or CBF; fabio and dxtbx.
- Confidence: HIGH that the pipeline can read and index it (geometry is complete and the axis is single). MEDIUM for the refinement comparison because the reference model is not bundled.

Collected 2019-03-07, SAINT 8.38A / SADABS / SHELXT / SHELXL.
- Instrument: Bruker D8 VENTURE, PHOTON-III C14, Mo K-alpha 0.71073 Å (a laboratory source; the monochromator/optic and hence the polarization factor are not stated on the page, UNVERIFIED).

The file name pattern (`..._rampT160K_...`) shows the frames come from a temperature ramp, not a single static run. Very small crystal, light atoms, S the only heavy atom.
- Siblings, same group, same layout, modulated phase (average-structure CIF bundled, satellites present, so poor choice for refinement but fine for spot finding and integration null tests): 174 K 10.5281/zenodo.18926010; 176 K 18926480; 178 K 18936043; 180 K 18936425; 185 K 18936742; 190 K 18937032; 200 K 18937433. About 426 MB each, CC BY 4.0.
- Format/reader: Bruker SFRM, fabio `bruker100image`, dxtbx `FormatBruker*`.
- Confidence: HIGH for reading and indexing; the bundled CIF gives the comparison model. MEDIUM-HIGH overall, the open question is run selection.

- URL: https://zenodo.org/records/10784740 ; DOI 10.5281/zenodo.10784740 ; Zenodo ; CC BY 4.0 ; no login
- Authors: P. A. Guńka (Warsaw UT), T. Strobel (Carnegie). Published 2024-03-06. Related paper: Strobel et al., Sci. Adv. 11, eadv6867 (2025), doi 10.1126/sciadv.adv6867; CCDC dataset DOIs 10.5517/ccdc.csd.cc2jgzkk and 10.5517/ccdc.csd.cc2jgzll.
- Files: `CaBC_Feb2023APS13idd.7z` 1.62 GB (md5 20c99add2d15b59d65a756ecf2e3ae36), `CaBC_Oct2022APS13idd.7z` 285.1 MB (md5 6935eebd4f231e56a7dbd5c212d645ff). 7z, so you need 7-zip; the Oct2022 file is the smaller one.

## Recommendation: first tests

1. Easy small-molecule set: Rochelle salt, Zenodo 10.5281/zenodo.7265997. Download `ktart2_cbf.imgcif` (62.5 kB) and `ktart2_cbf.tar.bz2` (728.6 MB). The bz2 stream can be unpacked from the front, so the first 60-100 frames (about 15-20 percent of it) are enough to test spot finding and indexing; the full 360 degree phi sweep is needed for a refinement. Geometry in the imgCIF is complete except for labelled distance/beam centre/units, which you should confirm against the CBF headers. You must supply the reference structure: look up Rochelle salt (KNaC4H4O6.4H2O) in the COD/CSD; this is not in the record. Second choice, if you want a bundled CIF and a tiny download: thiourea 130 K, Zenodo 10.5281/zenodo.18910433, `2_T130K_18MPC001.zip` (318.4 MB), SFRM + `.p4p` + `.cif` all in one zip; pick one single-axis run first.

2. Protein set: SBGrid 655 (lysozyme 6RT3, ESRF ID29, 120 images, 665 MB, CC0) for a quick indexing and reduction check against a deposited PDB entry with the cell stated; or thaumatin Eiger HDF5 (Zenodo 10.5281/zenodo.3385862, `Therm_6_2_master.h5` 61 kB + `Therm_6_2_000001.h5` 374.5 MB, 488 frames, CC BY 4.0) to test the HDF5/NeXus reader. Neither is a full-structure refinement test. The crystal-structure refinement step is better tested on the small molecules above.

3. DAC set: only Zenodo 10.5281/zenodo.10784740, `CaBC_Oct2022APS13idd.7z` (285.1 MB), the smaller file, as a probe: open the archive first, read the headers (wavelength, distance, step, rotation range, format), and decide then. Expect diamond reflections, a limited rotation range and probably more than one grain. Do not plan around it until the archive contents are known. The paper's refinement (Pm-3n, a = 7.0464(12) Å at 48 GPa for type-I) is the target and the CIFs are in the CCDC entries 2338099 and 2338100.

Unresolved before any run: polarization of the beam is stated nowhere in these records (it is a synchrotron-vs-lab question; set the polarization factor from the beamline, and check it as a free parameter in the refinement rather than assuming 0.5 or 0.99). The Rigaku `.rodhypix` and STOE `.xi` sets need a conversion route and are not first-test material.
